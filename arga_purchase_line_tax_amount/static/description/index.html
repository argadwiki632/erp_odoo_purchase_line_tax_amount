ODOO PURCHASE / TAX AMOUNT

Purchase Line Tax Amount

See tax on every purchase line.

Display the native Odoo tax amount on request for quotation and purchase order lines.

A clearer line-by-line view

Tax Amount appears after Taxes in the order lines and line detail form. The column is visible by default and can be hidden using the optional column selector.

Uses the standard read-only line tax amount in the order currency; no changes to tax calculations, totals, vendor bills or printed reports. With global tax rounding, line amounts may differ from the final document-level tax total.
